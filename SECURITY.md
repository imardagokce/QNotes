# Güvenlik Politikası

## Desteklenen Sürümler

Bu projenin sürüm **v0.1.x** desteklendiği belirtilmiştir.

## Güvenlik Bildirimleri

Güvenlik açıklarını bildirmek için GitHub Private Vulnerability Reporting üzerinden lütfen aşağıdaki adımları takip edin:

1. [GitHub Private Vulnerability Reporting](https://github.com/yourusername/yourrepository/security/vulnerabilities) bağlantısına gidin.
2. Güvenlik açıklarınızı ayrıntılı bir şekilde belirtin ve gönderin.

Güvenlik açıklarınızın hızlı ve etkili bir şekilde değerlendirilmesi için bu yöntem tercih edilmektedir.
